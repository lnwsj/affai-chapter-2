1เลือกสินค้า

ไปที่หน้าแค็ตตาล็อก เลือกสินค้าที่อยากทำโฆษณา มีให้เลือก 5 ล้านชิ้น

1.1
ค้นหาสินค้าที่สนใจ
⏱ 30 วินาที

พิมพ์ชื่อสินค้าในช่องค้นหา เช่น "iPhone", "ครีม", "รองเท้า" หรือเลือกจากหมวดหมู่ทางซ้าย

📸 ค้นหา "iPhone" → เจอสินค้าทันที

💡 เคล็ดลับ: ดู AI Score ถ้า >= 60 คือทำเงินได้, 80+ คือดีมาก 🔥
1.2
คลิกดูรายละเอียดสินค้า
⏱ 20 วินาที

คลิกที่การ์ดสินค้า → ดูรายละเอียดครบทุกอย่าง ราคา ยอดขาย ค่าคอมมิชชั่น

📸 หน้ารายละเอียดสินค้า — เห็นครบ 12 metrics

1.3
กดปุ่ม "เลือกไปหน้าเจน VDO"
⏱ 5 วินาที

กดปุ่มสีชมพู-ส้ม 🚀 เลือกไปหน้าเจน VDO → ระบบจะเปิดหน้าใหม่พร้อมโหลดสินค้าให้อัตโนมัติ

👉 มีปุ่มเดียวที่ต้องกดหลังเลือกสินค้า
🚀 เลือกไปหน้าเจน VDO
(อยู่ใต้รูปสินค้าในหน้า detail)

2เลือกนางแบบ (หรือไม่ต้องก็ได้)

เปิดหน้าเจน VDO แล้ว → ระบบจะ โหลดรูปสินค้าให้อัตโนมัติ คุณแค่เลือกนางแบบ

2.1
อัปโหลดรูปนางแบบ
⏱ 15 วินาที

คลิกที่ช่อง "1) ภาพนางแบบ" → อัปโหลดรูปคนที่อยากให้ถือสินค้า หรือเลือก preset 3 แบบ:

  • 👩 สาวไทยน่ารัก — แนะนำสินค้าแบบน่ารักสดใส
  • 👨 หนุ่มวัยรุ่น — แนะนำแบบเท่ๆ สายเทค
  • 🧑‍⚕️ ผู้เชี่ยวชาญ — รีวิวแบบจริงจัง น่าเชื่อถือ

📸 ช่องอัปโหลดนางแบบ + preset 3 แบบ

💡 ใช้รูปที่: เห็นหน้าชัด · พื้นหลังเรียบ · คนเต็มตัวหรือครึ่งตัว
ไม่ต้อง: ถ่ายเองก็ได้ (โหลดรูปจาก freepik หรือรูป influencer ที่อนุญาตให้ใช้)
2.2
ใส่ API Key (ทำครั้งเดียว)
⏱ 30 วินาที

ที่ช่อง 🔑 GenAIPro มุมขวาบน → ใส่ API key → กดบันทึก (ระบบจำให้ใน Chrome นี้ ไม่ต้องใส่ใหม่)

📸 ใส่ API key ครั้งเดียว ใช้ได้ตลอด

🔑 API key คืออะไร? เหมือนบัตรเติมเงิน — ระบบจะหักเงินจาก key นี้ทุกครั้งที่สร้าง VDO
ซื้อได้ที่ genaipro.io · 1 VDO ≈ 100 credits · 100 credits ≈ $0.30

3กดสร้าง

แค่กดปุ่มเดียว รอสักครู่ ระบบจะทำให้ทั้งหมด

3.1
กดปุ่ม "เริ่มสร้างวิดีโอ"
⏱ 5 วินาที

เลื่อนลงไปข้างล่างสุด กดปุ่มสีเขียวใหญ่ 🚀 เริ่มสร้างวิดีโอ

หลังใส่ครบทุกอย่าง กดปุ่มนี้:
🚀 เริ่มสร้างวิดีโอ
ระบบจะเจน 1 สไตล์ × 4 คลิป ใช้เวลาประมาณ 1-2 นาที
3.2
รอดู Progress
⏱ 1-2 นาที

ระบบจะแสดง 4 ขั้น:

  • ✅ แตกงานภาพสินค้า — ตัดรูปสินค้าออกจาก background
  • ✅ ส่ง Prompt — AI เขียนคำอธิบายวิดีโอ
  • ⏳ เรนเดอร์วิดีโอ — Google Veo 3.1 สร้างวิดีโอ (นานสุด)
  • ⏳ ตรวจสอบ — เช็คคุณภาพก่อนส่ง

📸 ขณะกำลังสร้าง — เห็น progress ทุกขั้น

⏰ ใช้เวลากี่นาที? ปกติ 1-2 นาที ต่อ 1 รอบ (4 คลิป)
ถ้า server ยุ่งอาจนานถึง 5 นาที — ไม่ต้องปิดเบราเซอร์ รอได้

4ได้คลิป!

เสร็จแล้ว! ดาวน์โหลดหรือโพสต์ได้เลย

4.1
ดูวิดีโอที่เสร็จแล้ว
⏱ ทันที

เมื่อเสร็จ ระบบจะแสดง "วิดีโอพร้อมใช้งานแล้ว" พร้อมวิดีโอ 4 คลิปให้เลือก:

📸 เสร็จแล้ว! 4 คลิปพร้อมใช้

4.2
เลือกคลิปที่ชอบ + ดาวน์โหลด
⏱ 30 วินาที

กดดูแต่ละคลิป → เลือกคลิปที่ชอบที่สุด → กด 📥 ดาวน์โหลด (อยู่มุมบนขวา)

  • ดาวน์โหลดมาเก็บในเครื่อง
  • อัปขึ้น TikTok ได้เลย
  • หรือส่งให้เพื่อนดูก่อน
💡 เคล็ดลับ: ลองดูทั้ง 4 คลิปก่อน เลือกอันที่ดีที่สุด
แต่ละคลิปจะได้ ท่าทาง + มุมกล้อง + อารมณ์ ต่างกัน (เพราะ AI สร้างใหม่ทุกครั้ง)

🎁 อยากได้แบบอื่นอีก?

พอทำเป็นแล้ว ลองต่อยอดแบบนี้

💡
Faceless Mode — ไม่ต้องมีนางแบบ

ถ้าอยากทำโฆษณาที่ โฟกัสที่ตัวสินค้าล้วนๆ ไม่มีคนโผล่

👉 กดที่แท็บ "🛍️ สินค้าล้วน" แทน "นางแบบ+สินค้า" → ระบบจะใช้แค่รูปสินค้า

เหมาะกับ: เครื่องสำอาง อาหารเสริม ของใช้ในบ้าน

💡
ทำหลายสไตล์พร้อมกัน

คลิกเลือก 2-6 สไตล์ พร้อมกัน (ไม่ใช่แค่ 1) → ได้ 8-24 คลิป ในรอบเดียว

มี 6 สไตล์ให้เลือก:

  • ⚡ ป้ายยาไวรัล (default) — เร็ว กระชับ ขายของ
  • 📦 แกะกล่อง — โชว์ packaging ตื่นเต้น
  • 💎 พรีเมียม — แสงสตูดิโอ คมกริบ
  • 🧑‍🏫 สาธิตวิธีใช้ — บอกสเต็ปชัดเจน
  • 🌿 มินิมอลธรรมชาติ — อบอุ่น น่าเชื่อถือ
  • 💬 รีวิว — เล่าปัญหา-แก้ปัญหา

API key คืออะไร? ต้องซื้อที่ไหน?
API key เหมือนบัตรเติมเงิน — ซื้อที่ genaipro.io
ราคา: ~$3 ต่อ 1,000 credits · 1 VDO ใช้ ~100 credits · สร้าง 4 VDO ใช้ ~$1.2
ต้องสมัครบัญชีไหม? ใช้แบบ Guest ได้มั้ย?
ได้! ไม่ต้องสมัครก็ใช้ได้ — ระบบจะสร้าง Guest ให้อัตโนมัติ จำไว้ใน Chrome นี้ 1 ปี
ถ้าอยาก sync งานข้ามเครื่อง → สมัครด้วย email (ฟรี)
ใช้เวลานานแค่ไหน?
ครั้งแรก: 5-10 นาที (เพราะต้องใส่ API key + อัปโหลดรูป)
ครั้งต่อไป: 1-2 นาที ต่อ 1 รอบ (4 คลิป)
ได้กี่คลิปต่อการกด 1 ครั้ง?

ใช้มือถือได้ไหม?
ได้! เว็บ responsive ใช้ได้ทั้งมือถือและ tablet
